# El secreto de Sacré Coeur

Juego AR con A-Frame 1.8.0 y AR.js 3.4.8.

## Uso
Subir el contenido de este ZIP a la raíz del repositorio. Para publicar cuando estés lista: Settings → Pages → Deploy from a branch → main → / (root) → Save.

Mientras Pages no esté habilitado, no habrá URL pública del juego. El repositorio puede mantenerse privado según las opciones de tu cuenta.

Abrir preparar.html para imprimir los marcadores y montar el recorrido. Probar la detección con un celular antes de entregar. La cámara requiere HTTPS o localhost.
